## 2025-06-08 - [Optimizing subset loops with SplitObject in R/Seurat]
**Learning:** Using `subset()` iteratively inside a `for` loop in Seurat creates severe O(n) CPU overhead due to repeated full-dataset passes. While using `SplitObject()` unconditionally *before* the loop is highly CPU-efficient, it duplicates the entire dataset in memory as a list. To prevent catastrophic Out-Of-Memory (OOM) failures in large scRNA-seq datasets, the split object must be explicitly removed immediately after the loop using `rm(<split_obj>); gc()`. Conditional caching of split objects across script sections should be avoided as it can cause stale data bugs.
**Action:** Always replace inner-loop `subset()` with a pre-loop `SplitObject()` when iterating over Seurat metadata groups. However, *always* append `rm(); gc()` directly after the loop is complete to safely free up memory before the script proceeds.
